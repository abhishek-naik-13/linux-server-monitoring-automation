
# Linux Server Monitoring & Automation

A hands-on Linux project using Bash scripting,
Cron, and AWS EC2.

## Project Goals

- Monitor CPU load, RAM, and disk usage.
- Automate old project log cleanup.
- Check Linux service status.
- Generate Linux user reports.
- Schedule recurring tasks using Cron.

## Technologies

- Linux (Amazon Linux)
- Bash Shell Scripting
- AWS EC2
- Cron
- Git and GitHub

## Current Progress

- [x] AWS EC2 Linux server created
- [ ] System monitoring script tested
- [ ] Log cleanup automation
- [ ] Service monitoring
- [ ] Cron scheduling
- [ ] Final testing

## Run the Monitoring Script

```bash
chmod +x scripts/system_monitor.sh
./scripts/system_monitor.sh
```

The report is saved in the project's logs directory.

## Learning Objective

Learn Linux administration and automate
routine server monitoring tasks.
